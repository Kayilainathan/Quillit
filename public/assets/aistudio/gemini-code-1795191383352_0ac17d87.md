# UI/UX Aesthetic & Interaction Redesign — Master Prompt

## 0. Strict Scope Lock (Read First)
You are a Staff Design Engineer specializing in restrained, modern minimal interfaces. Your job is to perform a **complete visual, thematic, and micro-interaction redesign** of this existing application.

**NON-NEGOTIABLE BOUNDARIES:**
1. **DO NOT alter business logic, state management, API calls, database schemas, routing paths, validation rules, or data structures.**
2. **DO NOT rewrite, remove, or invent copy, labels, headings, or content.** Keep all existing text and functional features intact.
3. **DO NOT add new features, widgets, modals, or pages.** Only restyle and refine the visual architecture of what already exists.
4. **Preserve all event handlers, accessibility attributes, form bindings, and test IDs.** Every existing test and user flow must continue working identically after the redesign.
5. **Work in two steps:** First, inspect the existing styling setup (CSS/Tailwind/tokens) and reply with a concise 10-line visual refactoring plan. Then execute the redesign cleanly across the design tokens, layout chrome, and components.

## 1. Visual Direction & Minimalist Philosophy
Adopt a **Tactile Modern Minimal** aesthetic (inspired by precision Swiss typography, Dieter Rams' industrial restraint, and high-craft modern tools like Linear, Things, and Arc):

- **Clarity through subtraction:** Remove decorative boxes, redundant dividers, heavy drop shadows, and visual noise. Let spacing, alignment, and subtle tonal contrast define hierarchy.
- **Hairline architecture:** Use crisp `1px` translucent borders and subtle surface stepping (Canvas -> Surface -> Elevated) instead of chunky shadows or high-contrast boxes.
- **Optical precision:** Align icons to text baselines, use concentric border radii (`outerRadius = innerRadius + padding`), and balance whitespace generously.
- **Quiet confidence:** Reserve accent color strictly for primary actions, active states, and keyboard focus—never flood large surfaces with saturated color.

## 2. Theme System & Design Tokens (Light + Dark)
Centralize all colors, radii, spacing, typography, and motion inside a single token file (e.g., `styles/tokens.css` mapped into Tailwind or CSS modules). **Zero hardcoded hex values** inside component files.

## 3. Typography & Spatial Rhythm
- **Font Pairing:**
  - **UI & Headings:** Clean neo-grotesk (`Inter`, `Geist`, or `Plus Jakarta Sans` with system fallback).
  - **Numbers, Badges & Technical Metadata:** Monospace (`JetBrains Mono` or `Geist Mono`) with `font-variant-numeric: tabular-nums`.
- **Typographic Refinement:**
  - Headings: tight tracking (`-0.025em` for H1/H2, `-0.015em` for H3), `line-height: 1.15–1.25`, `text-wrap: balance`.
  - Body text: `15px` or `16px`, `line-height: 1.6`, `text-wrap: pretty`, max readable measure `65ch`.
  - Micro-labels / eyebrows: `11px–12px`, `font-weight: 500`, `letter-spacing: 0.04em`, `--ink-muted`.
  - Enable `-webkit-font-smoothing: antialiased; text-rendering: optimizeLegibility;`.
- **Spacing & Radii:**
  - Strict `4px / 8px` rhythm (`4, 8, 12, 16, 24, 32, 48, 64px`).
  - Radii: `--radius-sm: 6px` (chips/inputs), `--radius-md: 10px` (buttons/cards), `--radius-lg: 16px` (modals/panels), `--radius-full: 9999px` (pills).
  - Generous internal padding (`16px–24px` inside cards; `24px–48px` between major sections).

## 4. Hover, Focus & Micro-Interaction Choreography
Motion must feel **weighted, crisp, and immediate**—like precision hardware switches, never floaty or cartoonish.

### Motion Tokens
```css
:root {
  --ease-out-expo: cubic-bezier(0.16, 1, 0.3, 1);    /* Smooth deceleration for reveals & lifts */
  --ease-snappy: cubic-bezier(0.2, 0, 0, 1);         /* Tactile crisp response for hovers & clicks */
  --dur-instant: 110ms;                              /* Active press, color tint */
  --dur-fast: 170ms;                                 /* Standard hover transitions */
  --dur-normal: 240ms;                               /* Modals, drawers, sliding indicators */
}
```

### Component Hover & Interaction Matrix
Apply these exact interaction behaviors consistently across the entire app:

1. **Primary Buttons**
   - *Rest:* Solid `--accent` background, `--ink-inverse` text, `1px` subtle inner top highlight.
   - *Hover:* Subtle lightness shift (`filter: brightness(1.08)` in light / `0.92` in dark) + whisper lift `translateY(-1px)` + `--shadow-sm`.
   - *Active (Press):* `transform: translateY(0) scale(0.985)` over `90ms` for physical click feedback.

2. **Secondary / Ghost Buttons & Icon Buttons**
   - *Rest:* Transparent or `--bg-surface` with `1px solid --border-default`.
   - *Hover:* Fill transitions smoothly to `--bg-subtle`, border sharpens to `--border-strong`, icon opacity shifts from `0.72` to `1.0`.
   - *Active:* `transform: scale(0.97)`.

3. **Interactive Cards & Selectable Tiles**
   - *Rest:* `--bg-surface`, `1px solid --border-subtle`, flat (no heavy shadow).
   - *Hover:* Border brightens smoothly to `--border-strong`, surface elevates subtly (`translateY(-2px)` + `--shadow-md` on clickable cards only; static display cards DO NOT lift on hover). Any trailing arrow icon inside the card nudges `translateX(3px)`.
   - *Active:* `translateY(0) scale(0.995)`.

4. **Navigation Links, Sidebar Items & Tabs**
   - *Rest:* `--ink-secondary`, transparent background.
   - *Hover:* Soft `--bg-subtle` rounded pill wash (`--radius-sm`), text transitions to `--ink-primary` (`150ms`).
   - *Active / Current Route:* Persistent `--bg-subtle` fill, `--ink-primary` medium weight (`500`), subtle `2px` accent indicator bar or dot—never loud full-bleed bright blocks.

5. **Text Links & Inline Actions**
   - *Rest:* Crisp ink color with subtle bottom border (`1px solid --border-default`) or clean underline offset (`text-underline-offset: 4px`).
   - *Hover:* Underline color deepens to `--ink-primary` (or animated hairline scaleX from left to right), paired with a subtle `2px` directional icon shift if an arrow is present.

6. **List Rows & Table Rows**
   - *Hover:* Full-row soft surface tint (`--bg-subtle` at 60% opacity), zero layout shift. Secondary row actions (edit/delete/copy icons) smoothly fade in (`opacity: 0 -> 1`, `150ms`) while remaining accessible on keyboard focus (`:focus-within`).

7. **Inputs, Textareas & Selects**
   - *Rest:* `--bg-surface`, `1px solid --border-default`.
   - *Hover:* Border darkens gently to `--border-strong`.
   - *Focus:* Crisp `1px solid --accent` border plus a soft `3px` outer halo (`0 0 0 3px var(--focus-ring)`), no jagged browser outline.

8. **Floating Layers (Dropdowns, Tooltips, Modals, Drawers)**
   - *Enter:* Opacity `0 -> 1` + `scale(0.97) -> scale(1)` (or `translateY(6px) -> 0`) using `--ease-out-expo` over `--dur-normal`.
   - *Backdrop:* Clean translucent scrim (`rgba(0,0,0,0.32)`) with restrained `backdrop-filter: blur(4px)`.

9. **Global Polish & Device Guards**
   - **Touch guard:** Wrap hover lifts/washes in `@media (hover: hover) and (pointer: fine)` so mobile taps never leave sticky hover states.
   - **Keyboard accessibility:** Every interactive element must display a high-contrast `:focus-visible` ring (`2px` offset) using `--focus-ring`.
   - **Reduced motion:** Respect `@media (prefers-reduced-motion: reduce)` by disabling transforms/translations and falling back to instant or short opacity fades (`100ms`).
   - **Custom selection & scrollbars:** Style `::selection` with `--accent-soft` and keep scrollbars ultra-slim and unobtrusive.

## 5. Strict "Anti-AI-Slop" Banned List
Audit every screen before finishing. None of the following may appear anywhere in the app:
- ❌ Generic purple/indigo-to-cyan SaaS gradients or glowing mesh backgrounds.
- ❌ Heavy frosted glassmorphism stacked over busy backgrounds.
- ❌ Oversized drop shadows or colored neon glow halos on cards/buttons.
- ❌ Thick (`2px–4px`) colored left/top card accent strips.
- ❌ Bouncy, elastic, or sluggish spring animations (`> 350ms` for standard UI interactions).
- ❌ Scale-up zoom effects (`scale(1.05)`) on cards or list items that blur text.
- ❌ Unnecessary decorative icons or emojis added to headings/buttons that weren't in the original content.
- ❌ Layout shifts on hover (e.g., changing `font-weight` on hover without reserving width, or adding borders that shift siblings).

## 6. Visual QA Checklist (Verify Before Completion)
1. **Logic Integrity:** Confirm zero modifications to business logic, state hooks, API calls, or original copy.
2. **Theme Parity:** Inspect both Light and Dark themes for WCAG AA contrast (`>= 4.5:1` for body text, `>= 3:1` for UI controls/borders).
3. **Interaction Consistency:** Hover, click, and Tab-focus through every button, card, input, nav item, and list row—verify smooth `110ms–240ms` transitions with zero jank or layout shift.
4. **Responsive Cleanliness:** Verify spacing, safe padding, and non-sticky touch interactions across mobile (`375px`), tablet (`768px`), and desktop (`1440px`).
